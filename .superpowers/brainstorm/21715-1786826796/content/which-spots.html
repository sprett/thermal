Which spots should appear as dots?

ParaglidingEarth has takeoffs and landings. Quiet dots either way — the sheet can still say which type you tapped.

A · Takeoffs only

Fewer dots, easier to scan. Landing lives in the sheet when you tap a takeoff, if PGE has one.

B · Both, same dots

Takeoffs and landings both plot. You only learn which is which after tapping.

C · Both, navy vs green

Still quiet dots — navy takeoff, climb-green landing. Type readable without a tap.
