Rules

On the sheet

  • Name · takeoff altitude
  • Wind rose: 0 faint, 1 possible, 2 good (navy)
  • Landing line only if PGE sent coordinates
  • No weather row, no PGE deep-link

Around it

  • Fly stays on top of the sheet (same as the in-flight hold button)
  • Tap empty map → sheet closes
  • Tap another site → contents swap
  • Selected dot is slightly larger

When things fail

  • First load: map with no dots until PGE answers — no spinner
  • Later failure: keep last good dots, no toast
  • Zoom < 8: dots clear, no request
  • Empty valley: empty map, that’s fine
